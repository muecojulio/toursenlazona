# toursenlazona

PWA Next.js de tours históricos. Node 24.x.

- 76 sitios, mapa Leaflet + OSM, voz, modo inmersivo, PWA.
- Índices en memoria (id, región, ciudad). No hay SQL.
- Caché Next + Cache-Control + SW tours-historia-v2.
- Privacidad: /privacidad.
- Headers de seguridad. Sin secretos.
- APIs sin key: Open-Meteo, Wikipedia/Commons, REST Countries, Sunrise-Sunset, Nager.Date, OSM, QR Server.
- Leaflet: https://github.com/Leaflet/Leaflet

Local: npm install && npm run dev
Vercel: Next.js, Node 24.x, repo privado.
